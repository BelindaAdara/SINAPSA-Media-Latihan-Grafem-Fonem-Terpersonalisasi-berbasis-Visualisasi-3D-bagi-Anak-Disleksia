This is the SINAPSA Expo/React Native JavaScript application. Follow [../SRS_Sinapsa.md](../SRS_Sinapsa.md) as the product source of truth.

## Platform

- Check `package.json` for the installed Expo SDK major version and use its versioned documentation before changing Expo APIs.
- Use `npx expo install <package>` for Expo-compatible native dependencies.
- Keep native platform folders generated by Expo; configure native behavior through `app.json` and plugins.
- Run `npm run lint`, `npm run test:logic`, and `npx expo export --platform android` when validating mobile changes.

## Navigation

- Use React Navigation with five bottom tabs and nested stacks, as required by the SRS. Do not introduce Expo Router.
- Keep screens in `src/screens/`; shared UI, hooks, API code, and utilities belong in their existing `src/` folders.

## Build

- EAS Build is configured in `eas.json`. Follow the EAS docs at https://docs.expo.dev/eas/ and do not run cloud builds without the user's Expo account.
